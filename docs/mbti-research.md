# MBTI 與寶可夢個性配對的研究依據

查證日期：2026-10-12。資料版本：`mbti-zh-hant-v1`，修訂版：`1`。

## 官方測評目前採用的方式

The Myers-Briggs Company 目前仍把 Global Step I／Step II 稱為最新版本；官方 FAQ 記錄這一國際修訂於 2018 年推出，不能描述為 2026 年新發明的測驗。

- **Global Step I**：英文版 92 題，辨識 E/I、S/N、T/F、J/P 四組偏好，形成 16 種四字母類型。
- **Global Step II**：英文版 143 題，包括 Step I 類型，另分析四組偏好各五個面向，共 20 個 facets，理解同型者之間的個別差異。這不是增加人格類型數量。
- **Probability Index**：Global 版以此取代過往 preference clarity index。這是官方問卷結果的統計指標，不能當作偏好強弱、人格能力或本站配對準確率。
- **Best-fit verification**：正式流程包含合格專業人士的解釋回饋，或 MBTIonline 的互動學習，讓當事人學習並核對最符合自己的類型。本人可以不同意問卷所報告的類型。
- **Step III**：另有用於理解個人如何運用與發展類型的工具；不是取代 Step I／II 的新版 16 型問卷。

來源：[Global 版與英文題數](https://www.themyersbriggs.com/en-US/Access-Resources/MBTI-Global-Version)、[官方 FAQ](https://www.themyersbriggs.com/en-US/Support/MBTI-Facts)、[Global Step II 報告範例，第 4 頁說明 20 個面向](https://www.themyersbriggs.com/hubfs/MyersBriggsCompany_January2026/pdfs/smp262149.pdf?hsLang=en)、[best-fit verification](https://www.myersbriggs.org/unique-features-of-myers-briggs/best-fit-type/)、[三種工具](https://www.myersbriggs.org/unique-features-of-myers-briggs/three-unique-instruments/)。

## 四組偏好與常見混淆

E/I 描述注意力與能量較自然朝向外在互動或內在反思；S/N 描述較自然注意具體事實或關聯與可能性；T/F 描述決策較先考慮一致的邏輯標準或價值與人的影響；J/P 描述面對外界時較偏好確定安排或保留彈性。這些都不表示能力高低，也不把人限制在某一種行為。

因此，I 不等於不會社交，E 不等於領導能力，T 不等於智力或沒有感情，F 不等於缺乏邏輯，J/P 也不等於勤勞／懶惰。類型只是個性理解的一部分，不能取代個人的經驗、情境與自述。

16Personalities 自述採用 NERIS 模型，重新調整 Big Five 面向，借用相似四字母格式並加入 A/T。**A/T 不是官方 MBTI 的新維度**。本站若接收 `INFP-T` 等輸入，只正規化四字母供配對使用，不把後綴當成官方 MBTI 類型。

來源：[官方偏好](https://www.myersbriggs.org/my-mbti-personality-type/the-mbti-preferences/)、[官方類型動態](https://www.myersbriggs.org/unique-features-of-myers-briggs/type-dynamics-processes/)、[16Personalities 的模型自述](https://www.16personalities.com/articles/our-theory)。

## 16 型的內容編寫方向

以下是原創繁中歸納，不是官方測評報告的翻譯。完整資料另外描述資訊處理、決策、互動、行動、優勢、可能盲點、壓力表現與成長建議。所有描述都是可供自我核對的傾向，不表示每位同型者必然如此。

| 類型與官方簡介 | 配對時保留的區別 |
| --- | --- |
| [ENFJ](https://www.mbtionline.com/mbti-types/enfj) | 從人的動機與潛能形成共同願景，主動鼓舞、協調與帶動成長；可能過度承擔他人的需要。 |
| [ENFP](https://www.mbtionline.com/mbti-types/enfp) | 從外界發現多種可能，以價值選擇值得嘗試的方向，熱情邀請與即興探索；需要照顧收尾。 |
| [ENTJ](https://www.mbtionline.com/mbti-types/entj) | 從全局建立長期策略，按成果與邏輯安排資源，直接推進系統改善；需要留意共識與人的節奏。 |
| [ENTP](https://www.mbtionline.com/mbti-types/entp) | 提出替代方案，以辯證比較可能性，在思想交流中重組問題；需要避免失焦與挑戰方式過強。 |
| [ESFJ](https://www.mbtionline.com/mbti-types/esfj) | 從群體日常需要組織具體照顧，重共同責任、合作與歸屬；需要保留自己的界線。 |
| [ESFP](https://www.mbtionline.com/mbti-types/esfp) | 注意現場氣氛與具體體驗，以接納和實際支持帶大家參與；需要預留長期安排。 |
| [ESTJ](https://www.mbtionline.com/mbti-types/estj) | 掌握事實、資源與流程，按明確標準分工並追蹤成果；需要充分聽取不同需要。 |
| [ESTP](https://www.mbtionline.com/mbti-types/estp) | 快速讀取現場機會，按實際得失行動並即時調整；需要把長期代價納入判斷。 |
| [INFJ](https://www.mbtionline.com/mbti-types/infj) | 整合深層意義與人的處境，聚焦有意義的願景，重少數深度關係；需要核對自己的推測。 |
| [INFP](https://www.mbtionline.com/mbti-types/infp) | 探索意義與成長可能，忠於內在價值，重真誠理解；需要把理想轉成可執行的小步驟。 |
| [INTJ](https://www.mbtionline.com/mbti-types/intj) | 在內在形成長期系統與策略，以邏輯檢驗路徑，重自主改善；需要確認現場資訊與人的回應。 |
| [INTP](https://www.mbtionline.com/mbti-types/intp) | 追問原理並建立一致的概念模型，獨立深入研究，隨證據修正；需要設定完成條件。 |
| [ISFJ](https://www.mbtionline.com/mbti-types/isfj) | 記住重要人物的具體需求，以耐心準備和持續照顧支持熟悉關係；需要表達自己的需要。 |
| [ISFP](https://www.mbtionline.com/mbti-types/isfp) | 留心當下體驗，以內在價值尊重個體，用自己的步調默默支持；需要說明界線與不滿。 |
| [ISTJ](https://www.mbtionline.com/mbti-types/istj) | 參照經驗、檢查細節，以一致標準穩定履行承諾；需要對新做法保留驗證空間。 |
| [ISTP](https://www.mbtionline.com/mbti-types/istp) | 拆解現場機制與因果，獨立試作並冷靜排錯，以實際幫忙表達支持；需要補充溝通與背景。 |

## 在本站的應用界線

- 已知類型的人可以輸入 MBTI 並補充個性；不知道的人只輸入個性也能配對。本站不新增問卷、不推定未知者的 MBTI，也不宣稱完成正式 best-fit verification。
- 16 型資料用於配對的先驗描述；具體個性自述應能補充或修正類型預設，不用四字母抹平同型者的差異。
- 配對依據是可觀察行為，例如獨立探索、守護同伴、團體合作、耐心準備與快速應變。關鍵詞權重是本站的創作性配對規則，並非官方 MBTI 分數或經過心理測量驗證的量表。
- 寶可夢的對照是娛樂性詮釋，沒有「官方寶可夢 MBTI」。不從 MBTI 直接推論寶可夢種族值、智力、能力、屬性或個人的心理健康。
- 輸出的相符分數是推薦系統排序訊號，不能稱為人格診斷的準確率。解釋應引用實際行為對應，並保留不同之處。
- `matching_text` 只使用摘要、資訊／決策／互動／行動風格與優勢。盲點、壓力與成長建議供閱讀使用，避免把「容易忽略細節」錯當成正向的「細節」匹配證據。

## 資料維護

`app/data/mbti_zh_hant.json` 是具版本的內容來源，各型記錄自己的來源與查證日期。代碼依字母排序，維持固定的 16 維索引。內容修改必須增加修訂版並重建相關配對資料；內容雜湊用於辨識內容變更。不得把官方問卷題目、計分演算法或付費報告長段內容複製到本站。
